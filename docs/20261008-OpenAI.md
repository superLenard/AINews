# OpenAI 遭遇营收预算滑铁卢？前9月年化营收不及市场预期

> 2026年10月初，OpenAI向投资者披露：截至9月底公司年化营收接近 **500亿美元**，明显低于多家媒体上月底报道的 **700亿美元**。数据一落地，美股AI概念股应声走低，市场对AI行业庞大投入能否换来足够回报的疑虑再度升温。

---

## 一、发生了什么：核心数字低于预期

据21世纪经济报道援引知情人士，**OpenAI近日告知投资者，截至9月底其年化营收（ARR）接近500亿美元**。这一数字与媒体上月底援引公司向投资者提供的信息所报道的 **700亿美元** 相去甚远，落差接近三成。

消息公布后，美股AI概念股周四普遍下挫：

| 标的 | 当日涨跌幅 |
| --- | --- |
| CoreWeave | **-7.77%** |
| 甲骨文（Oracle） | -5.48% |
| 美光科技 | -4.79% |
| 闪迪（SanDisk） | -4.90% |
| 英伟达（NVIDIA） | -2.94% |
| 纳斯达克综合指数 | 跌幅一度扩大至 -1.25% |

不过，10月9日又有消息释出：知情人士透露，**OpenAI预计到今年年底年化营收将达到或超过700亿美元，主要由企业业务增长推动**。也就是说，缺口被描述为"增速兑现的时点问题"，而非目标消失。

## 二、营收狂飙，亏损比营收更狂飙

OpenAI的收入曲线一直很好看，但另一边的亏损曲线同样陡峭。**每赚1美元，公司大约要亏掉2美元。**

| 期间 | 营收 | 经营表现 |
| --- | --- | --- |
| 2024全年 | 约37亿美元 | 尚处扩张期 |
| 2025全年 | 约131亿美元（年化214亿美元） | 亏损约80亿美元 |
| 2025年底年化 | 214亿美元 | — |
| 2026年2月年化 | 约250亿美元 | — |
| 2026年一季度 | 57亿美元 | 经营亏损约93亿美元 |
| 2026年二季度 | 67亿美元（环比+18%） | 经营亏损扩大至约123亿美元 |
| 2026年8月中旬年化 | 突破400亿美元 | — |
| 2026年9月底年化（披露） | 接近500亿美元 | — |

- **The Information** 获得的内部预测显示，公司 **2026年全年亏损约140亿美元**，现金流转正最早要等到 **2029年前后**，届时累计亏损可能超过 **千亿美元**。
- 作为参照，亚马逊上市后第一个十年累计亏损约30亿美元，Uber在盈利前累计烧掉约250亿美元——OpenAI仅一年的预计亏损已接近后者的总和。
- 高盛测算：**OpenAI每1美元收入对应约0.69美元亏损，算力成本占总支出超60%，预计直到2030年前后才可能实现正向现金流**。

## 三、为何"失速"：增速被 Anhtropic 大幅反超

营收不及预期的另一面，是竞争对手的强势崛起。

- **Anthropic 二季度初步收入超过115亿美元**，较一季度47.3亿美元环比增长逾140%，**首次在单季度收入上超越 OpenAI**，并实现小幅运营盈利。
- 驱动其增长的核心引擎，是面向开发者的编程工具 **Claude Code**——旗舰模型单次调用成本虽高，但准确率更高、无需反复运行，实际综合成本反而更具竞争力。
- 与此同时，OpenAI 的 ChatGPT 增长放缓，管理层近期动荡：首席营收官任职不足一年离职，首席运营官及曾被视为奥特曼接班人的高管相继出走。
- OpenAI 方面回应：随着7月一批新模型发布，三季度增速已有所回升；并预计到年底，**来自企业客户的收入将占总收入的一半以上**，正加速向企业市场转型。

> ⚠️ 需注意：两家公司收入统计口径不同——OpenAI 采用**净额法**统计ARR、剔除了云服务商分成，Anthropic 采用**总额法**、未剔除相关分成，数字不宜直接比较。

## 四、算力与估值：1.4万亿美元的承诺 vs 万亿估值

真正的压力来自那张"天文账单"：

- OpenAI 的**算力承诺总额约1.4万亿美元**，包括与软银、甲骨文共建的"星际之门"（Stargate）5000亿美元、甲骨文云服务3000亿美元、微软Azure 2500亿美元、英伟达最高1000亿美元、AMD 6吉瓦订单外加认股权证、博通10吉瓦定制芯片、亚马逊AWS 380亿美元、CoreWeave约220亿美元。
- 这笔账约为其当前年化收入的 **35倍**。
- 2026年3月，OpenAI 完成约 **1220亿美元** 巨额融资（亚马逊、英伟达、软银领投），投后估值约 **8520亿美元**，为全球最贵独角兽。

在估值压力下，IPO节奏一再推迟：

- 2026年6月8日，OpenAI 向 SEC 秘密递交 S-1 招股书，聘请高盛、摩根士丹利等投行，市场一度预期估值最高看至 **1万亿美元**。
- 9月，CEO 奥特曼明确表态"**不会在2026年上市**"，以安全与对齐为由，IPO 延至 **2027年**。

## 五、市场警示：AI泡沫论持续升温

营收"滑铁卢"只是压垮情绪的又一根稻草，更宏观的担忧早已在场。

- 桥水基金创始人 **达利欧** 10月7日在福布斯全球CEO大会上表示：大量举债资金正涌入AI，随着利率走高，**AI泡沫即将进入破裂阶段**，"我们已经离临界点很近了"。
- 英伟达8月底披露，已开始延长部分投资级大客户的付款期限，上半年**应收账款余额跳涨64%至630亿美元**——产业链"先交货、后收款"的信号。
- 宏观层面：美国10年期国债收益率9月从4.79%升至5.29%，美联储9月中旬加息25个基点，融资成本持续抬升。
- 科技巨头承诺未来数年投入近2.4万亿美元建设数据中心；高盛将四巨头2025—2030财年资本开支预测上调至5.3万亿美元。

## 六、结语

营收披露低于预期的瞬间，市场反应如惊弓之鸟——这背后是 **AI行业投入与回报之间的巨大鸿沟**。在基础设施建设持续扩张、企业估值高企、融资成本走高的三重压力下，AI企业能否用真实营收撑起万亿估值，已成为悬在整个行业头顶的问号。对 OpenAI 而言，500亿 vs 700亿的年化营收差，与其说是会计口径之争，不如说是市场对其"烧钱换增长"模式耐心的一次校准。
